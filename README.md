## 🧭 About Me

I work at the intersection of cybersecurity governance, cloud security, privacy,
identity, incident response, database controls, and analytics. My projects show
how I approach a problem from multiple perspectives:

- translate frameworks and requirements into practical controls;
- validate those controls with technical evidence;
- communicate risk clearly to leadership and business stakeholders; and
- build interactive tools that make security decisions easier to understand.

I am especially interested in opportunities across **GRC, cybersecurity, cloud
security, IAM, data protection, and security analytics**.
